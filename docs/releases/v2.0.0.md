# v2.0.0

Session GraphをWithMateのSession-bound MCPへ一本化するmajor releaseです。repositoryのprivate設定を維持します。

## 変更と前提

- [Session Graph Skill](https://github.com/natumekazuki/opencode/blob/c25bd2de632f69f8e1ee534ea78946c99b7e65f4/skills/session-graph/SKILL.md)は、MCPによる現在の記録の取得・要求の先行保存・再開時の復元・結果の同期を定めます。保存・Main/Auxiliary間の共有・表示はWithMateが担い、操作名・引数・schema・認可はruntime提供を正本とします。
- 共通規約の利用契機・記録権限、WithMate guide、review結果ファイルとGraph要約の責務を揃えました。OpenCodeのnative Skill discoveryと提供されたMCPを使用します。
- MCPが提供されるWithMate Sessionが必要です。未提供・取得失敗・結果不明を空のGraphや保存成功と扱わず、未確認条件に依存する作業だけを保留します。接続値・認証を配布設定へ固定しません。

## 互換性

Session Graphの保存CLIと専用helper・test・例・検証referenceを廃止する破壊的変更です。Skill名・配置入口を維持し、現行のMCP利用方針へ切り替えます。実設定・認証・Memory・共有記録等の利用者データと操作承認境界は保護します。WithMate本体の製品動作は本repositoryの保証に含めません。

## 検証

- Session Graph Skillの形式検査、入口・guide・READMEの静的整合と差分checkに成功しました。
- 固定task baseから削除前test全14件を抽出し、独立read-only審査を完了しました。削除したfilesystem helper専用testをMCPの動作保証とは扱っていません。
- 公開済みmasterのreview-test-value修正を通常mergeし、固定task baseから5現行recordsと14削除recordsの全19 transitionsをdiagnosticsなしで抽出しました。追加5件はv1.0.1の独立審査結果を再利用しました。

## 適用範囲と確認限界

配布資産の公開であり、実config・認証・外部管理Skillを上書きしません。新規OpenCode SessionでのSkill自動発見、resume/Compact時の実効動作、MCP接続・読書き・競合・通信失敗、Graph画面表示は本repositoryの検証では未実施です。静的確認や他providerの通常系保存の成功を代用しません。

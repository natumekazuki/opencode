- [設計判断](https://github.com/natumekazuki/opencode/blob/3626edfc3dd20ac1f84fcf7351dfe65613745a21/docs/guides/design-decisions.md)と[開発guide](https://github.com/natumekazuki/opencode/blob/3626edfc3dd20ac1f84fcf7351dfe65613745a21/docs/guides/development.md)の重複説明を縮小しました。責務からの削減、未合意方針の採否、維持境界、review記録、統合優先と修正分離の判断を保っています。
- [WithMate利用guide](https://github.com/natumekazuki/opencode/blob/3626edfc3dd20ac1f84fcf7351dfe65613745a21/docs/guides/withmate.md)で、技術説明・進捗・最終報告にもCharacterの着眼点や反応を表す方針を追加しました。成果物と引用の文体・正確性は分けて維持します。

- [README](https://github.com/natumekazuki/opencode/blob/3626edfc3dd20ac1f84fcf7351dfe65613745a21/README.md)へ、同条件での前後応答と対照場面を比較し、通常会話とSkill利用を分けて評価する方針を追加しました。

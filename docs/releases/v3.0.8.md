# v3.0.8

WithMateの親子Sessionで、実行権限が決まるタイミングと返信元の確認方法を明確にした互換修正版です。

## 変更内容

- [協同ガイドの実行条件](https://github.com/natumekazuki/opencode/blob/6c51b5e39af077ffc3bffb01b4f28ccc1803d6cb/docs/guides/withmate-collaboration.md#実行条件の選定)を更新しました。通常子の実行権限はWithMateが作成元の実行中Turnから解決し、同等の制限を維持できない別Providerでは作成しません。親子間の通常送信では、受付時に宛先の保存済み権限設定を使います。作成・送信時に権限を上書きせず、個別の作業に必要な操作許可は別に扱います。
- [返信元の確認](https://github.com/natumekazuki/opencode/blob/6c51b5e39af077ffc3bffb01b4f28ccc1803d6cb/docs/guides/withmate-collaboration.md#子が背景と判断範囲を確かめる)では、必要な場合だけ `Reply To` が指す一通を取得し、宛先・実送信元・操作許可とは区別します。参照先が欠けていても、最新発言などで補いません。
- 協同ガイドの末尾にあった根拠一覧、委譲ガイドの重複リンク、文章支援Skillの古い参照を整理し、利用する校正資料は上流の固定版へつなぎ直しました。

## 互換性・更新時の注意

Model・Depthが原因で未受付と確定した場合の再送手順は従来どおりです。ガイド・参照・ソース内の説明のみを更新しており、OpenCodeの設定例、Skillの実行ロジック、WithMateの保存済み設定を変更する必要はありません。

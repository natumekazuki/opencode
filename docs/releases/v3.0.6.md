# v3.0.6

OpenCodeの共通開発規約に、アプリ開発で適用する実装規約の基本セットを明記した互換修正版です。

## 変更内容

- [v3.0.5からの差分](https://github.com/natumekazuki/opencode/compare/v3.0.5...v3.0.6)では、[共通入口](https://github.com/natumekazuki/opencode/blob/c5cdad518a3c5cbdb596c452750173a2dacdf5a5/AGENTS.md)から[実装規約の基本セット](https://github.com/natumekazuki/opencode/blob/c5cdad518a3c5cbdb596c452750173a2dacdf5a5/docs/guides/development.md#実装規約の基本セット)を参照するようにしました。新規開発・初回整備では全体、通常の実装では変更に関係する範囲を扱い、既存の規約・ツール・同等の検査を優先します。
- 書式・命名・lintと該当する型検査、ファイル配置と依存方向、公開API・境界の契約を記すドキュメントコメント、重要な正常時・失敗時のテストを基本セットに定めました。
- commit・push・merge前で検査対象を分け、CIの要否は統合経路に必要な保証で判断します。Git hookを使う場合は手動実行やCIと同じ検査本体を用い、対象なし・未整備・未実行を区別します。

## 互換性・更新時の注意

変更は運用文書のみで、Skillの名称・配置・抽出CLI・出力形式、Session Graphの利用方針、agent定義、設定例は変わりません。既存アプリへのGit hookやCIの導入、規約の適用前に着手を自動停止する仕組み、個人設定の更新は含みません。

## 確認範囲

採用元の規約本文との一致、OpenCode用の参照先、v3.0.5からの変更範囲とGit差分の空白エラーがないことを静的に確認しました。実アプリへの規約適用、Git hook・CIの動作、OpenCode Sessionでの実応答は検証対象外です。

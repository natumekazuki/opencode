# v3.1.1

v3.1.0からの互換patch更新です。

- [共通指示](https://github.com/natumekazuki/opencode/blob/9ed0fe3114107b618b516f4e87bd0bbbd5b1fa42/AGENTS.md)では、依頼された結果と任された範囲から作業方法を選びます。根拠が足りないときは結論を限定し、権限が足りないときは該当する操作だけを止めます。
- 規約の変更だけを理由に、一律の前後比較、条件合わせ、モデルによる応答生成は求めません。比較が依頼に必要なら、結論に効く条件を選び、条件差で判断できる範囲を示します。既存の必須CI・検査は引き続き適用されます。
- [UIガイド](https://github.com/natumekazuki/opencode/blob/9ed0fe3114107b618b516f4e87bd0bbbd5b1fa42/docs/guides/ui.md)では、主内容と配置・デザイン、次に既存ラベルの言葉で伝えます。それでも不可欠な新しい補助説明は、最短の文案で実装前に明示承認を得ます。承認済みの意味・対象範囲は再承認不要で、判断を待つのはその説明に依存する変更だけです。読み上げ、安全確認、失敗からの回復は引き続き機能の一部です。
- [開発ガイド](https://github.com/natumekazuki/opencode/blob/9ed0fe3114107b618b516f4e87bd0bbbd5b1fa42/docs/guides/development.md)の、契約外の保証・制約・防御を新設する場合の明示承認は維持します。破壊的操作、外部公開、情報保護に関する境界も変わりません。

## 利用・互換性・移行

モデル・権限設定、Skillの名前・配置、設定や認証・履歴の形式は変わりません。データ移行は不要です。[配置手順](https://github.com/natumekazuki/opencode/blob/9ed0fe3114107b618b516f4e87bd0bbbd5b1fa42/README.md#配置と導入)に従って配布ファイルを同じ版に揃え、新しいOpenCode Sessionから使ってください。

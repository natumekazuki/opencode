# v3.1.1

v3.1.0からの互換patch更新です。

- [共通指示](https://github.com/natumekazuki/opencode/blob/46c364b23ac644d388937edc84017bd415696ad8/AGENTS.md)では、依頼された結果と任された範囲から作業方法を選びます。根拠が足りないときは結論を限定し、権限が足りないときは該当する操作だけを止めます。
- 規約の変更だけを理由に、一律の前後比較、条件合わせ、モデルによる応答生成は求めません。比較が依頼に必要なら、結論に効く条件を選び、条件差で判断できる範囲を示します。既存の必須CI・検査は引き続き適用されます。
- [UIガイド](https://github.com/natumekazuki/opencode/blob/46c364b23ac644d388937edc84017bd415696ad8/docs/guides/ui.md)では、任された範囲内の短い補助説明に一律の事前承認を求めません。補助表示は必要なときに限り、読み上げ、安全確認、失敗からの回復は引き続き機能の一部です。破壊的操作、外部公開、情報保護に関する境界も変わりません。

## 利用・互換性・移行

モデル・権限設定、Skillの名前・配置、設定や認証・履歴の形式は変わりません。データ移行は不要です。[配置手順](https://github.com/natumekazuki/opencode/blob/46c364b23ac644d388937edc84017bd415696ad8/README.md#配置と導入)に従って配布ファイルを同じ版に揃え、新しいOpenCode Sessionから使ってください。

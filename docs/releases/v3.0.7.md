# v3.0.7

WithMateの通常送信で、Model・Depthの不適合が原因で受け付けられなかったときの対応を明記した互換修正版です。

## 変更内容

- [通常送信と実行中の補足](https://github.com/natumekazuki/opencode/blob/1efe30c962e4db3636177ffa87a1c5ca9b64799e/docs/guides/withmate-collaboration.md#通常送信と実行中の補足)に、Model・Depthが原因で未受付と確定した場合に限り、送信元が宛先のカタログと選定方針に従って今回のModel・Depthだけを選び直し、新しい `requestId` で再送する手順を追加しました。適合候補がなければ不足を報告します。
- 受付結果が不明なら再送せず、元の `requestId` と正確な宛先で照会する既存手順を通常送信の節に集約しました。

## 互換性・更新時の注意

変更は協同ガイドと版別ノートに限ります。WithMateの送信API、OpenCodeの設定例、保存済みの選定方針は変更しません。自動再送や自動的なModel・Depthの代替は追加していません。

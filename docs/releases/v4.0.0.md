# v4.0.0

[共通コメント規約](https://github.com/natumekazuki/opencode/blob/851d18655802ffbb3f3381ca7dee0a3ec728a1df/docs/guides/code-comments.md)を導入します。公開API、非公開の主要処理、呼び出し形式を含むテストの宣言には役割と契約を記し、本文では分岐・反復・例外処理や長い処理の流れを説明します。

## 変更内容

- 新規・変更するテストでは、条件、期待する観測、検出したい故障と必要な根拠を言語に合うドキュメントコメントに記します。[通常のレビュー](https://github.com/natumekazuki/opencode/blob/851d18655802ffbb3f3381ca7dee0a3ec728a1df/docs/guides/test-changes.md#通常のreviewで確認する)でテストが守る契約と検出力、削除・移設後に残る保証を実装と合わせて確認します。必要なテスト実行と、別途必要な独立確認は引き続き行います。
- [UIガイド](https://github.com/natumekazuki/opencode/blob/851d18655802ffbb3f3381ca7dee0a3ec728a1df/docs/guides/ui.md)と[設計Skill](https://github.com/natumekazuki/opencode/blob/851d18655802ffbb3f3381ca7dee0a3ec728a1df/skills/design-ui-information/SKILL.md)では、利用者が終えたい作業から設計を始め、説明を足す前に原因となる操作や制約を外せるか考えます。比較や編集では広がった幅・高さを主作業に使い、結果の文言で既存の操作対象を不意に動かしません。短いフォームや本文の読みやすさ、意図した再配置、必要なエラー・回復情報は保ち、代表条件で元の作業を最後まで行えるか実画面で確かめます。
- WithMateの[通常子から直接親への報告](https://github.com/natumekazuki/opencode/blob/851d18655802ffbb3f3381ca7dee0a3ec728a1df/docs/guides/withmate-collaboration.md#明示報告turn終了親の受入)では、自力で進められる途中経過は配送せず、依頼単位で最終報告を一度届けます。判断が要る相談、重大障害の連絡、親の照会への回答は維持します。
- 配布元の[Git pre-commit](https://github.com/natumekazuki/opencode/blob/851d18655802ffbb3f3381ca7dee0a3ec728a1df/README.md#このrepositoryのgit-pre-commit)は、staged差分の空白・競合マーカー、検査スクリプトの追加・変更宣言のdocstring、変更に関連する配布資産を確認します。公開OpenCode設定例のJSON構文も検査します。
- [Gitの配布パス](https://github.com/natumekazuki/opencode/blob/851d18655802ffbb3f3381ca7dee0a3ec728a1df/README.md#この設定ホームでgit管理するもの)は明示許可方式になります。新しいローカルファイルは既定で除外され、配布したい新規Skillや設定例は登録が必要です。端末の認証データ、実設定のバックアップ、端末固有pluginは配布に入りません。

## 利用時の注意

Git pre-commitはOpenCodeの実行時設定とは別で、チェックアウトしただけでは有効になりません。利用先でコメントの存在・配置・形式を強制する場合は、[導入手順](https://github.com/natumekazuki/opencode/blob/851d18655802ffbb3f3381ca7dee0a3ec728a1df/docs/guides/code-comments.md#利用先での機械検査の導入)に沿って範囲と除外を決め、通常の検証コマンドへ接続してください。

# v3.0.5

Session Workspace運用の整備と、OpenCode nativeサブエージェント呼び出しの無効化を含む互換修正版です。

## 変更内容

- [委譲と作業領域](https://github.com/natumekazuki/opencode/blob/0ce1ead7ae7d885ffd4357dab5293a81455c3b05/docs/architecture/subagent-workspace.md)と[協同guide](https://github.com/natumekazuki/opencode/blob/0ce1ead7ae7d885ffd4357dab5293a81455c3b05/docs/guides/withmate-collaboration.md)に、通常Main Sessionの1 Session・1専用Workspace原則、子を起動する直接の親による起動前の専用領域準備、Git管理下の通常子への専用Worktree割当て（reviewを含む）、作業領域の再利用と回収の条件、非Git作業の専用directory運用を定めました。Auxiliaryとnativeサブエージェントは専有ルールの対象外です。
- 割当Workspaceの不在を理由に子Sessionへの送信が拒否された場合、送信元Sessionが保存したbranch・commitや保全した入力から領域を復旧する規定を[委譲と作業領域](https://github.com/natumekazuki/opencode/blob/dd546ed867859098b7ca8b71b658cd1524a7f80a/docs/architecture/subagent-workspace.md)に追加し、[協同guide](https://github.com/natumekazuki/opencode/blob/dd546ed867859098b7ca8b71b658cd1524a7f80a/docs/guides/withmate-collaboration.md)から接続しました。
- [共通入口](https://github.com/natumekazuki/opencode/blob/9d3d749c68930d215b0fb4706f395b808b1e042e/AGENTS.md)と[協同guide](https://github.com/natumekazuki/opencode/blob/9d3d749c68930d215b0fb4706f395b808b1e042e/docs/guides/withmate-collaboration.md)で、依頼・追加指示を親自身の言葉で構成し、ユーザー発言の転載や言い換えだけで済ませないことを明記しました。原文を扱う作業では依頼と資料を分けます。
- [設定例](https://github.com/natumekazuki/opencode/blob/15f8e97bb1676f482a2bc56dff57e1a2f3e2f06c/opencode.example.jsonc)のpolicyで、OpenCode nativeの `subagent` 呼び出しを `tool.use` / `subagent:*` のdenyで拒否します。agent定義ごとのsubagent許可は削除しました。[README](https://github.com/natumekazuki/opencode/blob/15f8e97bb1676f482a2bc56dff57e1a2f3e2f06c/README.md)・[委譲と作業領域](https://github.com/natumekazuki/opencode/blob/15f8e97bb1676f482a2bc56dff57e1a2f3e2f06c/docs/architecture/subagent-workspace.md)・[変更test](https://github.com/natumekazuki/opencode/blob/15f8e97bb1676f482a2bc56dff57e1a2f3e2f06c/docs/guides/test-changes.md)・[review-test-value](https://github.com/natumekazuki/opencode/blob/15f8e97bb1676f482a2bc56dff57e1a2f3e2f06c/skills/review-test-value/SKILL.md)の委譲先を独立したread-only担当の表現へ整え、native呼び出しが使えない場合も必須の独立審査を免除しないことを明記しました。WithMate通常子Sessionの操作はこのpolicyの対象外です。

## 互換性・更新時の注意

Skill名・配置入口、抽出CLI・result・metadata schema・adapter・Git差分選択、Session Graph SkillのMCP利用方針、agents/の定義は変更しません。設定例のpolicyは配布用の開始値であり、管理者policyや強制隔離ではありません。設定のmergeや上位policyの影響は実効設定で確認してください。既存homeへは対象文書と設定例の差分を反映し、実設定・認証・履歴等を上書きしないでください。

## 確認範囲

origin/master（4ae9282）からの4 commitの差分、共通条項・参照anchorの整合、`git diff --check`を確認しました。Skill scriptの既存test 116件は、TypeScript adapter依存を導入した上で全件成功しました。設定例はOpenCode CLI v2.2.5の `opencode debug config` で読込を確認し、deny policyが認識されました。実際のSessionでのsubagent拒否動作、新規Sessionでの実応答、承認dialog、WithMate接続、live配置は確認対象に含みません。

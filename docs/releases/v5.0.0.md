# v5.0.0

WithMate 7.1に合わせ、Session Graphの利用規則、専用Skill、配布許可を廃止します。旧経路との互換や記録の移行を提供しないため、major版を更新します。

## 変更内容

- [メモの保存と配送](https://github.com/natumekazuki/opencode/blob/ea4d0318aab68e55d02b1cf8db3e27ae7889e19e/docs/guides/withmate.md#sessionfolderとcrew-folder)では、継続に必要な自用メモはSessionFolder、他Sessionの判断に必要な共有メモはCrew Folderに置きます。共有時は変更点と参照を通常送信で届けます。既存の仕様・PR・課題をメモで二重管理しません。
- [自SessionのSession Instructions](https://github.com/natumekazuki/opencode/blob/ea4d0318aab68e55d02b1cf8db3e27ae7889e19e/docs/guides/withmate.md#自sessionのsession-instructions)は、持続する前提・制約・必須ゴールが追加・変更・失効したときに読み、無関係なユーザー記述を保持した全文を保存します。反映は次の新規Turnからで、親子間やMainとAuxiliary間では共有しません。read-only作業での限定的な記録は、対象repositoryや外部の正本を書き換える許可ではありません。
- [WithMateでのmerge](https://github.com/natumekazuki/opencode/blob/ea4d0318aab68e55d02b1cf8db3e27ae7889e19e/docs/guides/development.md#withmateでのmerge)は、`main`／`master` 宛てをGitHub PRに限定します。それ以外の宛先はWithMateローカルPRに提出し、ユーザーがGUIで提出commitとmerge先commitの組を承認するまで止まります。所定の経路や承認が利用できなければ、そのmergeだけを保留します。
- v4.0.0以降の[共通設計](https://github.com/natumekazuki/opencode/blob/8dd9ede3b6f3d294a7e31c69361cc669e1b392dc/docs/guides/design-decisions.md#必要な責務をどこで実装するか)と[並列委譲](https://github.com/natumekazuki/opencode/blob/8dd9ede3b6f3d294a7e31c69361cc669e1b392dc/docs/architecture/subagent-workspace.md#並列実装の割当てと受入)の変更も含みます。実装前に共通の責務を持つ提供元と利用先を決め、並列作業では唯一の実装担当・利用側・受け渡し順を割り当てます。親は統合版で利用側が共通実装を使っていることを確認します。

## 利用時の注意

OpenCode native子の呼出禁止、設定例の `subagent:*` のdeny、端末専用pluginを配布しない境界、WithMateの通常Session間の協同、Glossary、RelayGraphを維持します。WithMate外の作業に専用folderやAPIは求めません。この規約配布はWithMate本体の更新ではなく、既存の記録・実設定・認証・端末専用pluginを削除・変更しません。

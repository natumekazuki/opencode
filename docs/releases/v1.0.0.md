# v1.0.0

OpenCode CLI 2.1.4向けの個人設定・共通作業規約・Skillを配布する初回正式版です。repositoryのprivate設定を維持します。

## 配布内容

- [配置・導入と運用](https://github.com/natumekazuki/opencode/blob/18e5dd12e35367532b5b0ac717b88c184ad34caf/README.md): AGENTS.md、開発・設計・test・UI・WithMateのguide、委譲規約、接続runbookを同梱します。
- [設定例](https://github.com/natumekazuki/opencode/blob/18e5dd12e35367532b5b0ac717b88c184ad34caf/opencode.example.jsonc): 既定/build/plan/generalは `opencode-go/glm-5.3`、explore/lightは `opencode-go/glm-5.3-flash`、judgment/read-onlyは `opencode-go/kimi-k3.1-pro` とします。初期運用配分であり、性能比較の実測ではありません。
- モデルallowlist・無効化・自動fallbackは置かず、OpenCodeとOpenCode Goの両経路を残します。shell・外部directoryは承認確認を残し、read-only/exploreとplanには担当別のtool制限を設定します。OS sandboxと同等の隔離は提供しません。
- 自前の6 Skillとして session-graph、review-test-value、design-ui-information、relaygraph、japanese-tech-writing-review、natural-japaneseを同梱します。日本語文書の2 Skillは明示起動のみとします。
- WithMateのCharacter・SessionFolder等はturn prompt、managed Memory/Glossary MCPはhostからの一時供給を利用します。実URL・短命token・managed Skillを配布物へ固定しません。
- Codexを共通方針の基本の正本とし、3repositoryを独立完結させる変更反映ルールを定義します。製品固有のmodel・tool・path等は適応し、共通改善はCodexへ逆反映します。

## 維持対象と適用範囲

利用者向けのSkill名・配置入口、review-test-valueのCLI/result・metadata・source adapter・Git差分選択、およびSession Graphの保存・競合・cleanup契約を維持対象とします。

- 抽出契約: [metadata v2](https://github.com/natumekazuki/opencode/blob/18e5dd12e35367532b5b0ac717b88c184ad34caf/skills/review-test-value/references/comment-format-v2.md)、[source adapter](https://github.com/natumekazuki/opencode/blob/18e5dd12e35367532b5b0ac717b88c184ad34caf/skills/review-test-value/references/source-adapters-v1.md)、[Git選択](https://github.com/natumekazuki/opencode/blob/18e5dd12e35367532b5b0ac717b88c184ad34caf/skills/review-test-value/references/git-selection-v1.md)。
- 共有記録: [Session Graphの保存・競合・cleanup](https://github.com/natumekazuki/opencode/blob/18e5dd12e35367532b5b0ac717b88c184ad34caf/skills/session-graph/SKILL.md#共有ファイルの保存)。

内部実装・指示の表現・初期model配分・文書構成全体を固定するものではありません。実設定・認証・Memory・既存共有記録等の利用者データと操作承認境界は保護します。外部modelの提供・費用・品質やWithMate本体は本repositoryの保証に含めません。

`opencode.jsonc` は端末local設定としてGit対象外です。設定例を既存の実設定・MCP・認証へ一括上書きしないでください。WithMateのOpenCode対応providerが別途必要です。
